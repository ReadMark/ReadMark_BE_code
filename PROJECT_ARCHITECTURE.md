## 📝 플로우차트 설명

### 도형의 의미:
- **타원형** (시작/끝): 시작하거나 끝나는 곳
- **사각형**: 해야 할 일 (예: "책 추가하기", "로그인하기")
- **다이아몬드**: 결정해야 할 질문 (예: "계정이 있나요?", "페이지 번호를 찾았나요?")
- **화살표**: 다음 단계로 이동

### 주요 기능 흐름:
1. **시작**: 계정이 있으면 로그인, 없으면 회원가입
2. **메인 페이지**: 읽는 중/읽고 싶은/다 읽은 책 보기
3. **책 추가**: 새로운 책 정보 입력하고 추가
4. **독서**: ESP32로 책 선택 → 사진 찍기 → 페이지 번호 찾기 → 도장 받기
5. **마이페이지**: 내 통계와 책 목록 보기
6. **캘린더**: 날짜별로 독서 기록과 도장 보기

이 플로우차트는 **사용자가 실제로 무엇을 하는지** 중심으로 하나로 통합되어 있습니다! 🎯
